# Project Overview

This repository modernizes the original Masters project, **Traffic Management using Quality Methodologies**, into a reproducible Python analytics platform.

The original academic intent is preserved: identify traffic-delay Critical-to-Quality factors, measure process defects, analyze root causes, improve delay performance, and control the improved process using quality engineering methods.

## Original Methodology Preserved

- DMAIC
- DPMO and sigma level
- Pareto analysis
- P-charts
- Process capability
- R&R analysis
- Root cause analysis
- PDCA

## Engineering Upgrade

The upgraded version adds:

- Python source modules
- Streamlit dashboard
- Process metric calculations
- Reusable data-loading layer
- Unit tests
- Dockerfile
- GitHub Actions CI
- Clear data/docs structure

## Portfolio Value

This project now connects Quality Systems Engineering with modern software/data engineering: Python, Pandas, reproducible analytics, testing, CI/CD, and dashboarding.
